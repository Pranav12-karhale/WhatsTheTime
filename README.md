## Features
- **Modern UI**: A stunning glassmorphism design with a dark mode aesthetic.
- **Dynamic Background**: The background color and celestial bodies (sun/moon) transition automatically based on the time of day.
- **Format Toggle**: Seamlessly switch between 12-hour and 24-hour formats.
- **Responsive**: Adapts perfectly to various screen sizes.

## Architecture
- `index.html`: Contains the semantic structure.
- `clk.css`: Provides the styling, layout, and animations.
- `clk.js`: Handles the clock logic, format toggling, and dynamic sky background.
